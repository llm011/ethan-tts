对话模型

任何兼容 OpenAI 接口的服务都可以：DeepSeek、OpenAI、智谱、通义、Kimi，或本机的 Ollama / LM Studio。

接口地址

通常以 /v1 结尾，例如 https://api.deepseek.com/v1

API Key

只保存在本地数据库，不会出现在页面上

模型名称

例如 deepseek-chat、gpt-4o-mini、qwen2.5:7b

温度

0–2；对话建议 0.5–0.8

走系统代理

Windows/macOS 开着全局代理时，直连失败的才需要打开

代理地址

留空则使用系统代理，例如 http://127.0.0.1:7890

最大回复长度

64–2048 tokens；语音对话不需要很长

回答风格

这段 system prompt 决定模型怎么说话。语音对话最怕长段落，所以默认约束了长度、去掉了 Markdown，并要求数字口语化。

语音识别

把你说的话转成文字。两种模型都在本地运行，录音不会上传到任何服务器。

当前使用

切换后会释放旧模型，下一次说话时加载新模型

识别在按下说话并停顿后触发，一次只处理一小段录音；
热态下 0.6B 模型约 0.2 秒返回一句。

读音纠正

把模型容易读错的词换成你想要的读法，例如把 Qwen 读成「千问」。只改变合成时的发音，产物里仍保留原文。

→
不勾选时 Qwen / qwen / QWEN 都会命中

模型与资源

默认仅加载 4bit 模型。可选模型不会自动下载。

手机访问

同一个 Wi-Fi 下，用手机浏览器打开本机地址即可使用语音对话页。

新建音色

使用 1.7B VoiceDesign 模型，需要单独下载。

建议 10–20 秒、单人、无背景噪音，最大 20 MB。请确保已获得本人同意。

保存时只做本地转码，不上传云端、不训练。首次合成由 0.6B Base 模型零样本提取音色；该模型与预设音色模型不同，需要单独下载。
